# KKTC araç ithalat vergileri: kaynaklar

Maliyet motoru bu kalemleri hesaplayacak. Oranlar yönetici panelinde tutulur ve aşağıdaki kaynaklarla teyit edilir.

| Kalem | Not |
| --- | --- |
| Gümrük vergisi | Menşe, araç tipi, yakıt ve motor hacmine göre |
| Fiyat İstikrar Fonu (FİF) | Motor hacmi kademeli; FİF emirnamesi |
| Özel fon / stopaj | Şahıs ithalatında özel fon, galeri (satıcı ruhsatı) ithalatında stopaj |
| Rıhtım harcı | Deniz yolu ithalatında |
| GKK | |
| Bandrol | Oran + sabit tutar |
| KDV | Matrah: CIF + vergiler |

## Kaynaklar

- KKTC Gümrük Dairesi / GBS Tarife Maketi: https://giris.gbs.gov.ct.tr/tarife-maketi
- Neveser Gümrükleme, kamuya açık araç gümrük hesaplama aracı
- Motorlu Taşıt Araçları Yaş Sınırlandırılması Tüzüğü (5 yaş kuralı)
- Referans (yalnızca okuma; lisanssız, kod kopyalanmaz): https://github.com/RYucel/japanexport

Oranlar bir gümrük komisyoncusuyla teyit edilmeden canlıya alınmaz.
